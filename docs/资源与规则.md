# 任务、数据和模型资源核实

核实日期：2026-10-17。任务优先为多个常见废弃物的检测与四分类；共同比较单位为每图四分类出现集合，定位仅对传统检测单独评估。

默认采用北京生活垃圾四分类口径：可回收物、有害垃圾、厨余垃圾、其他垃圾。具体投放仍依物品材质、污染和电池化学体系决定；普通“battery”标签不能直接全部视作有害垃圾。未知是识别状态，不是其他垃圾。

正式运行模型前先固定数据划分，使用 SHA256 去重并检查感知近重复。开发集用于选型；测试集不用于调阈值、映射或提示词。现成模型训练集不透明时不能把来源相同的数据声称独立于其训练。

## 基础版完成时的候选与排除结论

- 实际读取 `khoaliamle/Garbage_Detection` 权重元数据，仅有 `garbage` 和 `rubbish` 两类，不能区分四分类，排除。
- 检查 WasteSnap（Mayank14/Multi-Class-Waste-Image-Classification-Dataset）实际 770 张图片；虽然模型卡声明 CC BY 2.5，开发候选中含明显素材水印、插画，“Hazardous waste”多为警示牌，且没有检测框。整套资源排除出模型验证与最终示例，保留核实记录，不传播这些图片。
- 可实施的多物品路线：Ultralytics YOLO-World v2，根据固定物品词表做开放词汇目标检测；来源 https://docs.ultralytics.com/models/yolo-world/ ，权重 https://github.com/ultralytics/assets/releases/download/v8.3.0/yolov8s-worldv2.pt 。权重已取得，但尚未把成功加载当作任务验证。先在开发集真实推理；如四类覆盖仍不足，继续调整候选或使用可靠框标注微调。
- 数据改用 Wikimedia Commons 的逐图元数据，保留来源页、作者、许可链接、下载 URL 和哈希，并在推理前划分同源组。搜索类别只是候选标签，最终真值需要逐图复核，不能当作现成答案。含水印、示意图、跨物品歧义的图片不直接纳入评估。
- 某些物品照片并非已丢弃现场；采用时必须写明“假定这些物品已经决定丢弃”的实验条件，不声称其为真实垃圾现场。预训练模型是否曾见过公开照片无法完全确认，独立性只保证相对于本项目的开发与调优。
