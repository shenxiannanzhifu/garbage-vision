# 任务、数据和模型资源核实

核实日期：2026-10-17。任务优先为多个常见废弃物的检测与四分类；共同比较单位为每图四分类出现集合，定位仅对传统检测单独评估。

默认采用北京生活垃圾四分类口径：可回收物、有害垃圾、厨余垃圾、其他垃圾。具体投放仍依物品材质、污染和电池化学体系决定；普通“battery”标签不能直接全部视作有害垃圾。未知是识别状态，不是其他垃圾。

| 来源 | 核实结果 | 使用决策 |
|---|---|---|
| https://github.com/Candy-CY/Pytorch-garbage-classify | README 为图像分类、ResNeXt101 等；LICENSE 路径返回 404，未确认许可证 | 仅理解参考方向，不复制代码，不引用其准确率作为本项目结果 |
| https://huggingface.co/ShihoAI/yolov8s-garbage-detection | AGPL-3.0，六类，缺少有害类；作者说明弱定位标注 | 不能独立覆盖所需四类 |
| https://huggingface.co/khoaliamle/Garbage_Detection | 模型卡 MIT，含 garbage_detector.pt，类别须读取权重核实 | 待开发集验证 |
| https://huggingface.co/datasets/khoaliamle/Garbage_Classification_YOLO | 模型卡 MIT；实际是 10 类 classify/train、val、test，没有检测标注 | 可作分类候选，不能假称检测数据；来源许可仍需审查上游 |
| https://huggingface.co/keremberke/yolov5n-garbage | 模型卡无清晰许可证；专用检测但须核实具体类别 | 暂不采用 |

正式运行模型前先固定数据划分，使用 SHA256 去重并检查感知近重复。开发集用于选型；测试集不用于调阈值、映射或提示词。现成模型训练集不透明时不能把来源相同的数据声称独立于其训练。
