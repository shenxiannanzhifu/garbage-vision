# 模型选择与能力边界

在固定 19 张开发图上测试 YOLO-World v2 s/l、YOLOE-11l、不同英文候选词表及 SAM2.1 tiny + CLIP ViT-B/32。21 张测试图从未用于这些选型预测。失败实验保留在 evidence/v0.2.0，未删除失败来改善结论。

YOLO 候选对烟头、荧光灯等漏检严重。最终使用 SAM 自动分割候选区域，再用 CLIP 比较物品和背景文本；足够确定者映射四类，含混电池/灯具保留未知。

默认 SAM 使用 24×24 点网格、一层裁剪、1024 输入尺寸；CLIP 编码带少量背景的 RGB 区域。多尺度裁剪改善部分小物品覆盖但增加耗时；掩膜外置灰的开发实验更差，未作为默认。参数见 config/local_model.json，各次预测保留参数指纹。SAM 掩膜质量及 CLIP 余弦相似度都不是经过校准的垃圾类别概率。

四类成功样例：塑料瓶 commons-179028310、厨余 commons-136457085、烟头 commons-79335127、荧光灯 commons-9690809。19 张开发图中 12 张类别出现集合完全一致，其余有错分、遗漏或额外类别。不能由这些开发数据断言泛化准确率。F1 将由经过手工小样例核验的评分程序计算。

当前开发批次每图平均推理约 12.37 秒，CUDA 峰值已分配内存 2,255,367,168 字节（约 2.10 GiB），不等于全部驱动显存占用；首次加载另计。

没有进行微调：数据只有图片级类别标签，缺少可靠的物品框/掩膜，不能把 SAM 错误预测当真实标注循环训练。训练垃圾检测器需要补充真正的定位标注和足够训练数据。当前只是实测实验基线，无微调或 mAP 声明。

SAM 常分割瓶身、灯管局部或包围烟头的地面，外接框不保证是完整物品。跨尺度去重不彻底，不能精确计数。开发集中“其他垃圾”仅 1 张，混合类别和未知场景不足。四分类假定主体已决定丢弃，瓶子清空清洁、食物分离包装，桌面和固定设施作为背景；API 同样遵守这一任务范围。
