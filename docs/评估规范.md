# 冻结前的共同评分规范

共同任务是每张图片内“确定出现的四分类集合”。同类别有多个实例只计一次。两方案必须处理同一方向校正 RGB 图片并记录同一 image_id；API 不能使用本地预测。没有框真值，不计算 mAP；定位质量只进行案例分析，不能与 API 自述信心比概率。

主指标是所有图片等权平均的 precision、recall、F1（先逐图计分，再平均）。辅助报告四分类集合完全一致率、聚合 TP/FP/FN 的 micro 指标、每类别指标和简单/复杂背景分组。未知项不映射成“其他垃圾”，只从确定类别集合排除，并单独报告含未知图片比例。

成功但空预测对非空真值记零；错误、未配置、超时均以空预测计分并报告失败率，不删除。对未来可能加入的空真值：成功且空预测的逐图分数记 1，假阳性或运行失败记 0。逐类别零分母记 0。当前 40 张清单都含非空四分类标签，不会利用空图提高主分数。漏掉整个记录、重复 ID、图片哈希不匹配时拒绝评分。

正式运行前冻结：Git 提交、推理相关文件、提示词、分类规则、本地参数、API 模型/输出上限/网络方式、两份权重哈希、完整测试清单和图片哈希、依赖。密钥从不写入冻结文件。每图完成后即时落盘，失败保留；中断的收费请求视为状态未明，不能静默重新调用。

测试集 21 张：可回收 8、厨余 3、其他 6、有害 4。来源是 Wikimedia Commons 作者描述及 Codex 预先视觉复核，非独立真人真值。不是 40 张均衡测试集，多类别混合/遮挡/未知场景不足；同作者分组不能保证所有图片统计独立，公开预训练数据重叠无法排除。只能报告这个小样本的探索性结果。

计时分别记录首次模型加载和推理/API 请求耗时；API 包含网络，CPU/GPU 不等价。缓存表示权重已加载，不是重复利用图像结果。费用按返回 usage 和已核实公开价格估算，不当作用户实付账单；无 usage 的错误保留“未知”，不臆测免费。正式测试失败样例不得删除或替换，不能根据测试分数改阈值后仍称未见测试。

评分实现 `garbage_vision/evaluation.py`；`tests/test_evaluation.py` 用可手算的多标签样例核验，和真实模型预测分开。入口 `scripts/score.py` 不调用模型或网络。
