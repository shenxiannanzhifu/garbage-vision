# 实际运行视频录制说明

状态：尚无最终视频。当前环境的浏览器自动操作曾被自动审批拒绝，助手没有绕过限制，也不会用截图合集冒充视频。以下供用户最后实际录制，视频完成前不得正式标为 v1.0.0。

## 录制前

1. 双击 `启动项目.cmd`，浏览器打开 http://127.0.0.1:8501 。不要录入 .env、密钥管理页面或 GitHub 凭据。
2. Windows 11 可按 Win+Shift+R，选择浏览器区域并开始屏幕录制；如果该快捷键不可用，打开“截图工具”的视频录制模式。也可在浏览器前台按 Win+G 使用 Xbox Game Bar。
3. 视频保存到项目 `exports/demo.mp4`（Git 已忽略大型导出），最终按考核平台要求单独上传；不要仅给脚本文档。

## 建议展示顺序

- 说明视觉问题和四分类范围：已经决定丢弃的物品，北京口径，材质/污染不明时保留未知。
- 展示启动成功和真实原图。选择 Empty Plastic Bottle.jpg，只运行本地，等待结果出现，解释真实框、分割质量与相似度。
- 使用已经预算授权的同图双侧运行，说明 API 图片独立输入。视频可展示已成功运行且仍在页面中的真实结果；再次点击 API 会产生新请求，不能把录屏当作无限调用授权。
- 展示一个困难开发例：Bales of PET bottles closeup.jpg。说明本地错误/遗漏，不把所有图片都描述为成功。不要用独立测试图反复演示调参。
- 下载 JSON、CSV 和本地标注图，打开 JSON 查看两侧同一 image_id；API 没有框就不画框。
- 切换图片，确认旧结果消失；解释未知与其他垃圾的区别。
- 展示真实评估报告及 Git 历史，说明小样本、非独立真人标签和定位不精确的限制。填写个人体验后再用自己的话总结。

## 完成检查

必须实际打开视频并确认可播放、字迹清晰、等待后有真实结果、没有密钥，不能只有口头说明。可覆盖重点后结束，不要求固定时长。
