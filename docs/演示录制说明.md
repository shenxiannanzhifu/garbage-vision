# 演示录制说明

当前可以准备录屏。网页默认为 SAM2.1 + CLIP；YOLO 定位训练及补漏候选仅用于实验，未替换默认模型。无需等到模型完全不犯错，演示应同时呈现成功和局限。最终时长按考核要求决定。

1. 说明项目目标：同一图片下比较本地视觉与远端多模态方案，输出垃圾四分类及不确定项。
2. 双击 `启动项目.cmd`，打开 http://127.0.0.1:8501 ，使用空塑料瓶样例实时运行本地模型，讲解框、类别、未知项和耗时。
3. 点击“查看本图已保存的大模型实测（不收费）”，或侧栏“复评结果”。明确说“这是此前真实调用保存的结果”，展示记录时间；不要称作现场 API 请求。它不检验当前远端连接。如果考核要求实时双侧调用，需另行联调后现场展示，不能用回放替代。
4. 运行一张困难图片，指出实际出现的漏检或不确定项，说明模型没有精确计数保证。
5. 下载并打开 JSON 和本地标注图，说明两侧使用同一图片哈希、失败记录也保留。
6. 打开 `docs/模型对比与收尾说明.md`，展示原默认、定位训练、补漏候选的同组对比；说明历史回归不是新独立测试，候选未全面达标，网页保留默认方案。
7. 展示真实 Git 历史及自己填写的感悟，用自己的话解释一个代码流程。不要照读不理解的技术名词。

使用 Win+Shift+R（支持录屏的截图工具）或 Win+G。录制前关闭密钥、账单和私人页面；录制后播放检查。建议保存 `exports/demo.mp4`，视频不自动进入 Git。当前没有完成的视频，软件 AppTest 也不是录屏。
