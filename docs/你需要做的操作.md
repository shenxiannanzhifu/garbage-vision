## GitHub 登录说明（已完成，以下用于以后需要重新登录时）

原因：私有 GitHub 仓库需要你本人授权电脑访问；网页已登录不代表本地 Git 已登录。

操作位置：`C:\Users\Cipher\Documents\Codex\2026-10-17\zhe-2\outputs\garbage-vision\登录GitHub.cmd`

1. 关闭之前的报错窗口。编码问题已修复；随后遇到的 unexpected EOF 是授权请求的连接中断，脚本已加入连接兼容设置和手动重试。
2. 在刚才的项目文件夹中重新双击 `登录GitHub.cmd`（隐藏扩展名时显示为 `登录GitHub`）。
3. 出现 `Authenticate Git ... (Y/n)` 时按回车；出现 `One-time code` 后再按回车打开浏览器。一次性代码以本次窗口显示为准，旧代码不再使用。
4. 浏览器中输入本次代码，点击 `Continue`，再确认授权 GitHub CLI。没有自动打开时访问 https://github.com/login/device 。
5. 完成浏览器授权后，窗口应提示登录完成；仅出现验证码还不代表成功。如果连接再次断开，可按脚本提示回车重试（最多三次）或退出并将错误发给助手。

回复内容：当前窗口的提示，或完成后回复“已登录”；不要发送密码或令牌。
