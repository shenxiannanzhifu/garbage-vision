1. 关闭之前的报错窗口。编码问题已修复；随后遇到的 unexpected EOF 是授权请求的连接中断，脚本已加入连接兼容设置和手动重试。
2. 在刚才的项目文件夹中重新双击 `登录GitHub.cmd`（隐藏扩展名时显示为 `登录GitHub`）。
3. 出现 `Authenticate Git ... (Y/n)` 时按回车；出现 `One-time code` 后再按回车打开浏览器。一次性代码以本次窗口显示为准，旧代码不再使用。
