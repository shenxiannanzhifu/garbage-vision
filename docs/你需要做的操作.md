# 你需要做的操作

2026-10-20：本次模型对比已收尾，可以开始本人体验、感悟、代码理解和录屏。实验候选没有替换网页默认模型；无需重新配置账号，也不用继续等待训练。技术实验完成不等于个人材料和最终提交已完成。

## 1. 亲自跑一次并保存结果

1. 双击项目根目录的 `启动项目.cmd`，等待启动后访问 http://127.0.0.1:8501 。使用期间保留启动窗口；关闭窗口会停止网站。
2. 展开“使用开发样例”，选择 `Empty Plastic Bottle.jpg`，保持“同时运行大模型”不勾选，点击“开始识别”。观察原图、框、可回收物结果及耗时。
3. 点击“查看本图已保存的大模型实测（不收费）”。这是此前真实请求的记录，页面显示原时间；不是本次重新请求。如当前图片没有该按钮，在侧栏“复评结果”查看历史同图对比。
4. 再选择困难样例 `Bales of PET bottles closeup.jpg`，运行本地识别，观察漏检、未知或错误，不要求它一定正确。记下你实际看到的差异。
5. 下载 JSON 实验记录和本地标注图，打开确认内容。阅读[模型对比与收尾说明](模型对比与收尾说明.md)，分清网页默认模型与实验候选。

本轮不需要新增付费调用。若主动勾选大模型并点击识别，会向 NexaVLinks 发送图片并可能扣费；已有配置不代表网络始终稳定。历史记录可用于讲解，但不能冒充现场请求。若考核要求现场双侧 API 调用，需要单独安排一次真实联调。

## 2. 填写自己的内容

打开[项目说明与个人感悟](项目说明与个人感悟.md)，填写末尾六处“待你填写”。技术说明已整理好；个人经历必须以你实际操作为准，不能把助手执行的训练写成你亲自训练。填写姓名、班级、日期等考核需要的信息。

阅读[代码导览与答辩](代码导览与答辩.md)，至少能解释：SAM 与 CLIP 分别做什么、相似度为什么不等于正确率、API 失败怎样计分，以及为什么训练候选有提升却没有替换默认模型。不会的部分可以继续问。

## 3. 录制实际演示

按[演示录制说明](演示录制说明.md)录制真实操作。Windows 可用 Win+Shift+R 的截图工具录屏；若系统不支持，可用 Win+G。展示本地实时推理、明确标注的历史 API 结果、一个困难案例、导出、模型对比和个人理解。

建议保存为项目目录下 `exports/demo.mp4`。录完自己播放，检查画面、声音和下载内容；不要录入 `.env`、密钥或账号敏感页面。之后告诉助手视频的完整路径，以便检查材料是否齐全。目前尚无已完成视频。

## 4. 最后核对并本人提交

- 确认考核的提交格式、截止时间，以及是否要求现场 API 调用；不把历史回放说成实时调用。
- 仓库是私有仓库，按考核要求给指定评审提供访问权限，或提交允许的源码包。
- 提交代码仓库、当前项目说明/个人感悟、对比报告和实际演示视频。旧 `v1.0.0-rc.1` 压缩包不包含本轮更新，不能当作最新源码。
- 本人材料和视频完成后再做最终核对；目前不创建正式 `v1.0.0` 标签，也不宣称已通过考核。
