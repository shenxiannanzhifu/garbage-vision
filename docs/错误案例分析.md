## API 失败与解释边界

commons-133246916、commons-26750498、commons-18975566 返回 HTTP 成功及真实用量，但内容未通过严格结构校验，计为 error、空预测、F1=0。没有重试、换样本或把服务端有响应当识别成功。

本次适配器在结构校验通过后才保存 response_text，因此这三条无效文本正文未保留；只保存了响应 ID、用量、图片/提示词哈希、耗时和通用解析错误。无法从这些记录准确区分是哪一字段违规，不猜测为网络失败或某种具体幻觉。后续版本可改进无效响应的脱敏诊断，但不得据测试输出调提示词后仍宣称该测试未见。

成功结果的分类集合一致不保证物品描述和理由完全准确。例如开发塑料瓶的 API 理由提到“残留液体极少”，无法仅凭单张图证实污染程度；本实验分类规则是假定清空清洁后投放，真实使用仍需核对。
