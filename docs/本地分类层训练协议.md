# 本轮训练与验证协议（预测前）

目的：在当前 SAM2.1 tiny + CLIP ViT-B/32 上执行真实监督梯度训练，并检验是否改善新图片的四分类集合。用户要求先完成本轮优化并告知，暂不进入视频、最终交付或考核提交。

训练层为 512 维 CLIP 分类向量：从当前文本向量初始化，冻结图像编码器、文本编码器与 SAM。仅有整图物品标签，不训练定位、不能报告检测 mAP。没有样本的类别向量保持不变。没有调用或训练远程多模态 API。

数据来自有公开许可的 Commons 图片。先看原图和作者说明，再标注；搜索词不是标签。只判断已经决定丢弃的主要物品，背景设施不计，无法辨认的灯/电池保留未知。排除绘图、化学品容器、未穷尽标注的混合场景、明显同源冗余等。已有 61 张历史测试图及同作者/近重复图不进入本轮。全部类别标签和划分先固定，不能根据预测好坏换图。

按作者和 64 位 dHash 汉明距离不大于 5 的近重复连通组划分，文件哈希重复也合并。旧开发图可用于训练；为保证验证有有害类，旧开发图 commons-5559269 所在组留给验证。新测试图没有参与先前模型选择。作者/感知哈希不能保证所有转载关系都已识别；参考由 Codex 视觉复核，不是独立真人金标准。

训练：种子 20261019，Adam 学习率 0.01，150 次全批梯度更新，交叉熵温度 20；每张图四种完整视图：原图、镜像、亮度 0.9 和 1.1，补边后进入 CLIP。增强不增加独立样本数。每标签等权、标签内每来源组等权。L2 锚定强度固定为 10、100；与原分类向量混合强度固定为 0.25、0.5，共四候选。禁止看测试结果增添候选或改阈值。

验证选择：优先未知/背景误报不增加且无失败的候选；按集合完全正确张数、平均逐图 F1 排序，相同则优先强锚定、弱混合。若没有候选在验证集同时改善正确张数和 F1，仍测试最佳训练候选以留下真实结论，但禁止升级默认模型。

测试前冻结唯一候选、权重哈希与测试清单。升级须同时满足：验证可升级；新测试正确张数和平均 F1 均提高；未知/背景误报不增加；四个已知类别各自 TP 均不下降；无运行失败。达不到就保留当前默认配置，不能因为执行了训练就宣称优化有效。

两方案复用真实 SAM 分割缓存，分类计算是真实运行；这种耗时不能宣称整套模型变快。证据保存到 `evidence/v0.6.0/local-training/`，训练权重在被 Git 忽略的 `weights/trained-head-v06/`，数据的署名、来源、许可证和哈希在清单中。
