# 识废：同图双方案垃圾识别项目说明

## 问题与范围

本项目比较本地深度学习和远端多模态 API 如何判断生活垃圾四分类。输入为同一张图片，输出为物品/区域、四分类、依据和未知状态。默认本地 Windows 网页，不包含账号系统、公网部署或摄像头。按北京生活垃圾口径，假定主体已决定丢弃，瓶子先清空清洁，食物与包装分离；材质/污染等看不清时不强行归类。

## 实现

Python、PyTorch、Ultralytics、CLIP、Streamlit、Pillow 和 httpx 构成主链路。图片先实际解码、校正方向并统一 RGB，两方案独立读取同一输入。SAM2.1 tiny 负责分割区域，CLIP ViT-B/32 负责区域和文本匹配，再映射四分类。网页显示框、清单和耗时；API 通过百炼 qwen3-vl-plus 提交图片和版本化规则，校验 JSON，不虚构框和概率。导出 JSON、CSV、中文标注图。

SAM 的分割区域可能是物品部件。开发中用户发现空塑料瓶的瓶盖被列为 LED 灯泡候选，四分类未知；据此加入基于真实掩膜包含关系的低分未知碎片过滤，保留被过滤候选供审计，同时把未知区域名称显示为“待确认区域”。这不是普遍解决识别错误，必须用全部开发数据回归。

## 数据与实验状态

Wikimedia Commons 逐图保存作者、来源页、许可、哈希；开发集 19 张、测试集 21 张，按来源作者分组并查重复。标签依据作者元数据与 Codex 视觉复核，非独立真人标注；不把大模型预测当真值。

YOLO-World/YOLOE 候选在开发集覆盖不足，保留失败实验后采用 SAM + CLIP。尚未针对垃圾微调，原因是没有可靠实例定位标注和足够训练数据；不报告 mAP。

初版默认模型的 19 张开发图逐图平均 F1 为 0.701754，类别集合完全一致 12/19；每图平均推理 12.37 秒。此数值是瓶盖修复前的开发实验，不是最终独立测试成绩。修复后重新跑完开发集，类别集合与 F1 不变，含未知图片从 9/19 降到 8/19；没有据此声称泛化能力提升。

API 首次成功识别开发塑料瓶，耗时 12.97 秒，1766 输入/50 输出 token；公开价格估算 0.002266 元，免费额度与实付账单未核实。一张成功只证明接口可用。

正式对比已完成，冻结代码为 3442a3f。21 张测试图：本地逐图平均 Precision 0.5714、Recall 0.6667、F1 0.6032；API 三项均为 0.8571。集合完全一致分别为 10/21 和 18/21。API 3 次结构失败计零，不重试、不删除。按类别统计，本地有害垃圾假阳性较多，API 厨余类受到两条结构失败影响。

[完整逐图报告与图表](../evidence/v0.4.0/final-test/report/对比报告.md)由原始记录生成；[错误案例分析](错误案例分析.md)解释瓶坯/烟支被识成荧光灯和整灯只出现未知局部等错误。测试数据没有用于后续调参。

本次平均本地推理 14.749 秒、API 请求 4.354 秒；两批并行且有安装下载负载，不能当作隔离性能基准。正式 21 次 API 公开价估算 0.055116 元；含开发/网页验证和最初成功联调，所有已返回用量的调用合计估算 0.067926 元。实际账单及免费额度未核实。

软件在全新虚拟环境通过 31 项检查，含真实 GPU 页面链路；安装复现复用了同一电脑的 Python 解释器、下载缓存和校验过的权重，不等同于全新操作系统或 CPU 性能验证。

## 适用场景与限制

本地方案不需要逐次外部服务请求，可输出分割区域，但小目标、堆积、背景、物体部件容易出错，不能精确计数。远端方案可结合语义说明分类理由，但解释也可能错误，必须检查结构、费用、网络和未知状态。两方案意见一致不代表正确。

21 张测试图是探索性小样本，类分布不均，多类别混合和未知场景不足；公开预训练数据重叠不可完全排除，作者分组也不保证所有图统计独立。项目不能充当实际投放的权威判定工具。
