# 数据与四分类规则

分类口径：《北京市生活垃圾管理条例》2019 年修正版第七十七条：菜叶、果皮果核、残食属于厨余；可再利用的纸、塑料、玻璃和金属属于可回收物；废荧光灯管、节能灯、废药品，以及规定种类的废电池属于有害垃圾。烟蒂和使用过的卫生纸巾按其他垃圾处理。

本次可读取的条例文本为 [LawRefBook 法规镜像的固定版本](https://github.com/LawRefBook/Laws/blob/24f29392293ce672d608e19c2bffff10401fe6a8/DLC/北京地方法规/地方性法规/北京/北京市生活垃圾管理条例(2020-09-25).md)。已核对第七十七条原文；北京市政府官网当前连接失败，尚未完成官网全文交叉核验。镜像不能保证包含后续修订；项目是固定口径的课程实验，实际投放按所在地最新要求。不得把这一状态写成“已核实最新官方目录”。

分类实现见 `config/categories.json`。条例中的其他垃圾兜底定义不等于模型没认出来就能判其他垃圾：项目将识别未知保留为 `category=null`。普通 battery 不知道化学体系，不能统一判有害；密封灯罩无法区分荧光灯和 LED，也应保留不确定。

## 实验对象

实验假定主体物品已经决定丢弃，饮料瓶先倒空清洁、食物先与包装分离。桌面、地面、灯架、食槽等承载设施是背景。只凭照片不能证明物品已废弃，不能鉴别隐藏污染、灯管内部成分或药品是否过期。规则里的物品词表表示可尝试识别的范围，不表示每类都通过实测；当前代表对象为饮料瓶、果蔬/食物残余、烟蒂、外露式荧光灯。

## 来源、划分和复核

- `data/manifests/commons_candidates.json`：86 张下载成功的初始候选及逐图作者、许可、原始链接和哈希；另有 8 条下载错误记录。
- `commons_review.json`：每张候选的采用/排除决定及理由。排除宣传图、图标、看不清主体、危险化学品包装、难以可靠标全类别的混合物，以及重复近照。
- `dev.json`：首批 19 张开发图（可回收 6、厨余 6、其他 1、有害 6）。
- `test.json`：21 张尚未运行模型预测的测试图（可回收 8、厨余 3、其他 6、有害 4）。同作者同来源组、完全重复及 dHash 距离不超过 5 的候选先归组，再用固定哈希划分。各组不跨开发/测试。

这些标签由图片作者的物品描述和 Codex 逐图视觉复核共同建立，在预测前保存。**没有独立真人标注或真实检测框**；不能声称人工标注一致性已验证，也不能报告检测 mAP。模型预测没有作为真值。保留真值来源和复核说明，方便随后人工抽查。

21 张测试图不足建议的 40 张，类间分布不均；同一作者的不同照片也不能自动视为统计独立。多物品主要是同类堆积，尚缺充足的多类别混合场景和独立未知样本。这是小规模课程实验，不代表一般垃圾识别准确率。公开预训练模型可能见过 Commons 照片，无法排除预训练重叠；仅保证未用本项目测试预测选型。

## 获取及署名

运行 `python scripts/download_data.py --split dev` 可按冻结 URL 获取图片并校验 SHA256；`--split test` 获取测试图，获取不等于推理。下载内容发生变化会停止，不能换图保留原 ID。

每张图按清单中的 `license` 和 `license_url` 使用；署名包括 `author`、`title`、`source_page`。CC BY-SA 图片的改图应遵守相同方式共享条件。原图、联系表和改图未提交 Git，仅提交可复现来源清单。网页展示示例时同步显示逐图署名。

WasteSnap 因水印、插图与标签适配问题整套排除；未将其用于任何模型预测或最终展示。
