# 图像理解 API 配置

推荐阿里云百炼华北 2（北京）`qwen3-vl-plus`。已于 2026-10-17 读取官方[视觉理解文档](https://help.aliyun.com/zh/model-studio/vision)、[密钥说明](https://help.aliyun.com/zh/model-studio/get-api-key)、[价格表](https://help.aliyun.com/zh/model-studio/model-pricing)及 [Base URL 总览](https://help.aliyun.com/zh/model-studio/base-url)。模型支持图片输入及兼容 Chat Completions 协议；总览明确原有北京公共端点仍可使用，已设为模板默认值。

需要你做：本人登录并在本地填写配置。原因：助手不能替你注册、实名、取得密钥或批准费用。

1. 打开 https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key ，登录阿里云账号，选择华北 2（北京）。如需开通百炼，按官方页面完成。
2. 在 API Key 页面创建或复制北京地域的可用密钥。不要把密钥发送到聊天或截图中。
3. 双击项目中的 `配置API.cmd`，记事本会打开已忽略提交的 `.env`。
4. 在 `GV_API_KEY=` 后粘贴密钥。Base URL 和模型名保持默认，业务空间 ID 留空即可。
5. 把 `GV_API_ENABLED=false` 改为 `GV_API_ENABLED=true`，保存关闭。只保存配置不会发请求。

完成标志：网页右侧显示 API 已配置。回复“本地已配置”，不要发送密钥。实际收费调用前还需确认预算；网页勾选并点击运行会发送当前图片和分类规则到服务商。

## 费用与限制

核实价格：北京地域 qwen3-vl-plus 单次输入不超过 32K token 时，输入 **1 元/百万 token**，输出 **10 元/百万 token**；32K–128K 为 1.5/15 元，128K–256K 为 3/30 元。免费额度与开通时间相关，不能假定你的账号必然免费。

当前 21 张测试图、若每图不超过 8,000 输入 token 且输出最多 2,048 token，单次估算 0.02848 元，21 张约 0.60 元；每图都重试一次约 1.20 元。此处只是基于假定 token 数的估算，真实账单由返回 usage、实际模型/地域/价目决定。开发验证也有额外调用。**已经有一次真实成功调用，尚未授权批量付费评估。** 首张图返回 1766 输入 / 50 输出 token，公开单价估算 0.002266 元，实际免费额度与账单未核实。 批量前会用真实开发调用核对用量，再给出调用数量与预算请求。

最多两次请求，仅对限流或指定服务器错误重试；鉴权失败、无效 JSON 和超时不自动重试。超时可能已经计费，重试前应查看服务商记录。模型别名可能更新，正式评估须记录响应中的模型标识、时间、提示词和配置指纹。

2026-10-18 本地配置读取检查已通过。首次单次联调在本机代理连接阶段失败，返回用量为空，不能视为真实识图成功。经用户另行允许一次尝试后，直连真实调用成功；项目默认不继承环境代理，不改动系统设置。如其他服务需要代理，可在本地增加 `GV_API_USE_ENV_PROXY=true`。首次联调入口 `scripts/probe_api.py --confirm-single-paid-call` 始终只尝试一次，不能未经预算授权自行反复执行。

其他兼容服务可修改 provider、Base URL、模型和密钥；只有核实支持图片及协议后才能使用。没有配置时本地模型仍可独立运行。
