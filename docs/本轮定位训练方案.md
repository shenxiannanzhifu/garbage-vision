# 本轮定位训练与停止条件

用户授权本地训练与多模态离线诊断并行；若这一轮仍没有可验证的改善，停止并报告，不自动启动另一条优化路线。新收费识图尚未授权。

## 可检验的改动

上一轮仅训练 CLIP 类别向量，新 25 图由 20 张正确降到 18 张，候选已拒绝。本轮训练 YOLOv8n 的垃圾物品定位权重，用真实检测框提示 SAM 生成真实掩膜，然后使用现有 CLIP 与分类规则。检测置信度、SAM 掩膜质量和 CLIP 相似度分别保留。生产默认配置在完成门槛判断前保持原值。

## 数据与来源

- TACO 官方数据发布：<https://zenodo.org/records/3587843>，DOI `10.5281/zenodo.3587843`，CC BY 4.0；作者 Pedro F. Proença、Pedro Simões 及 TACO 贡献者。数据许可依据为该发布元数据，不能用上游代码 MIT 许可替代数据许可。
- 从官方 ZIP 按 HTTP Range 读取文件；验证 ZIP 条目 CRC、解压大小，记录源文件与规范化图像 SHA-256。归档 `TACO/data/annotations.json` SHA-256 为 `ac1ec605c9e1fcda767970de3457c69b4a43b62c02aca8c4c80f51d1b5ae8449`。
- 初始按固定种子排序取 batch 1–9 的 700 图训练、10–11 的 100 图验证、12–15 的 100 图测试。测试批次内另外纳入所有只含当前支持物品标签的图片，供预测前视觉复核；这是有范围限制的分层便利样本，不能声称代表任意生活垃圾照片。
- TACO 全部实例保留并统一为“垃圾物品”前景；不把所有电池、塑料包装直接映射到有害或可回收。训练与检测测试针对定位能力，四分类另作评分。
- 使用上一轮训练集中的 11 张已视觉复核图片补充灯管、果皮果核、纸巾、未知灯泡与电池的实际物品框。固定设施和密集重叠且无法完整标注的图片排除。坐标按方向校正后的实际像素固定。这些是 Codex 视觉标注，不是独立真人金标准。
- 用 SHA 与 dHash（距离不超过 4）排查重复；保留测试、优先排除训练重叠项。批次隔离不等于作者隔离，dHash 也不能保证找出所有近重复。
- YOLOv8n 初始公开权重来自 Ultralytics/YOLOv8 固定版本 `27f858f2dc238503a66ce10248cf7ec71a3ded5d` 的镜像，SHA-256 `31e20dde3def09e2cf938c7be6fe23d9150bbbe503982af13345706515f2ef95`，AGPL-3.0，与项目当前许可证一致。原图、缓存和权重不入 Git。

## 一次训练、一次选择

单次 YOLOv8n 监督训练：最多 60 个 epoch，验证早停 patience 12，640 像素、batch 8、AdamW、固定随机种子；SAM 和 CLIP 冻结。实际参数和源码哈希在训练前固定。训练日志保留完整损失和验证曲线。

检测器最佳 epoch 只按检测验证集 mAP50–95 选择。检测阈值 0.15 / 0.30 / 0.50 与整图兜底开关的六种组合，只在保留的 17 张 Commons 验证图上选择；先比较类别集合完全正确张数，再比较 F1、未知/背景误报。测试不得反过来更换候选或阈值。

新 TACO 四分类子集在预测前复核并固定，只覆盖其实际存在且可确定的类别。历史 25 张 Commons 图仅作四类及背景的回归检查，不再称为新独立测试。

## 接受门槛

验证完全正确张数必须增加；新图完全正确张数至少增加 2 张且平均 F1 增加；历史回归完全正确数、F1 和各类别 TP 不下降；未知/背景误报不增加；无推理失败。定位 mAP 提升不能单独决定替换网页模型。任何条件未过则保留原模型并停止，先向用户报告结果。

数据规模小、有害与厨余覆盖不足，因此即使过门槛，也只能说明有限样本上的候选改善，不能据此宣称最终交付或真实日常使用可靠。缓存区域的耗时不能当作端到端提速证据。

## 执行入口

`scripts/experiments/prepare_detection_data.py` 下载与生成隔离的 YOLO 数据；`train_detector.py` 固定协议并训练；`evaluate_detector_pipeline.py` 验证选择、冻结候选、执行测试和门槛判定。全部为离线本地模型运行，不发起付费识图请求。证据保存于 `evidence/v0.7.0/detection-training/`。
