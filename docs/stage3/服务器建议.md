# 三阶段服务器建议与费用

报价核对日期：2026-10-22。以下是官方公开标价，不是已购买资源；账号资格、区域库存、税费和最终结算页仍需确认。当前尚未获三阶段服务器预算或新收费模型调用预算。

## 推荐：先用 CPU 按量完成一次远端演示

优先选 Ubuntu 24.04 LTS、8 vCPU、16 GiB 内存、至少 80 GiB 磁盘，单 API worker。此为本项目建议起点，须在实际机器核实内存峰值和两张图耗时。本机 Linux CPU 的两图约 145 秒（含加载）和 120 秒，云端共享 CPU 可能更慢；不能保证相同速度。本机 GPU 更快，但现有 CPU 镜像已经完成真实链路验证，短时 CPU 部署的依赖和成本更易控制。

| 档位 | 公开套餐与规格 | 官方美元标价 | 短期费用估算 |
|---|---|---|---|
| 最低演示起点 | DigitalOcean Basic Regular，8 vCPU / 16 GiB / 320 GiB SSD，无 GPU | $0.14286/小时，套餐月上限 $96 | 8 小时约 $1.15；24 小时约 $3.43 |
| 更流畅的 GPU 候选 | Lambda 单卡 NVIDIA A6000 48 GB，14 vCPU / 100 GiB / 512 GiB SSD | $1.09/小时，税费另计 | 8 小时 $8.72；24 小时 $26.16 |

GPU 档显存和内存明显高于当前模型需求，是官网可核实的整机实例候选，不是最低硬件需求。上线前还需实际验证 NVIDIA 驱动、Container Toolkit、CUDA 12.8 镜像及模型推理；未实测其耗时。暂不选会被中断回收的竞价实例。

建议先批准 CPU 档最多 24 小时试部署，资源费用总预算上限可设为 $5（含预计税费和必要流量；如结算预估超出先停止采购）。这只是建议，尚无购买授权。若不能使用该供应商的账号或支付方式，再按国内供应商实际结算报价调整，不默认用户有外币支付条件，不用未核实的促销价格替代报价。

## 费用边界与停止方式

DigitalOcean 该套餐按秒计费，最低收费为 60 秒或 $0.01 中较高者，套餐月用量上限 672 小时。仅在 Linux 关机、停止 Docker 或在控制台关闭电源仍计费；要结束实例计费必须销毁实例。销毁会删除实例盘，先把源码版本、数据库、图片、配置和证据安全备份到 D 盘，再由用户确认释放。另购快照、块存储、额外流量等可能独立计费，本方案不主动勾选备份、额外磁盘或付费附加服务。预算提醒不是自动停费保证。

Lambda 的表内金额只按官网实例时价估算；存储、税费、终止规则和最低充值情况在开通前按控制台核实。不把关闭 SSH 窗口当作停止计费。

两档均不包含 NexaVLinks 图像请求费用。真正的服务器双方案联调另需批准：固定使用现有两张开发样例，每图最多一次、总计最多两次，不自动重试；金额上限需先按当前服务商模型价格和账单单位核对后由用户确认。

## 访问方式

服务器上仅让 nginx 绑定 127.0.0.1:8080，API 和数据库不公开。本人和评审通过 SSH 隧道访问，浏览器仍打开本机地址；服务器地址、用户名和密钥入口确定后再给一条已填完整的 Windows 命令。无需购买域名。本方案的账号登录、付款及 SSH 访问授权需用户本人完成；私钥和模型密钥不发到聊天或公开仓库。
