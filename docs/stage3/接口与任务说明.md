# 三阶段接口与任务

开发接口版本：`3.0.0-dev`。Windows 开发地址 `http://127.0.0.1:8000`；容器 nginx 入口为 `http://127.0.0.1:8080/api`。除存活探针外，配置了访问令牌时均需 `Authorization: Bearer <本机配置中的令牌>`。实际令牌不应出现在公开示例、日志或聊天中。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/health/live` | 进程存活；不证明模型已加载 |
| GET | `/health/ready` | 检查权重存在、模型是否加载、任务上限与收费次数；权重存在不等于推理通过 |
| POST | `/v1/tasks` | multipart 图片创建任务，返回任务 ID 与 created |
| GET | `/v1/tasks?limit=20&offset=0` | 最近任务分页；limit 为 1～100 |
| GET | `/v1/tasks/{id}` | 状态、参数、图片哈希和已保存的两侧结果 |
| GET | `/v1/tasks/{id}/image` | 经方向校正的任务图片 PNG |
| GET | `/v1/tasks/{id}/annotated` | 本地成功结果的标注 PNG |
| GET | `/v1/tasks/{id}/export?format=json` | 完整任务 JSON；format=csv 可导出结果表 |
| DELETE | `/v1/tasks/{id}` | 删除终态任务图片与结果，保留最小防重记录 |

## 创建与查询

创建时须带 UUID 格式的 `Idempotency-Key` 请求头，表单字段为 `file`、`include_api`（默认 false）、`similarity_min`（默认 0.28，范围 0.20～0.40）。图片最大 12 MB、2400 万像素，解码规则沿用原实现。文件名不用作磁盘路径。

接口先保存任务后返回 HTTP 202，模型在后台顺序执行，网页只轮询任务。队列最多接受 8 项未完成任务，满载返回 429。重复提交同一编号、同图同参数会返回原任务且 created=false；不同图片或参数返回 409。删除后复用原编号也返回 409，防止无意再次识别。

`source_sha256` 记录原始上传字节，`image_id` 记录规范图片；两侧结果必须匹配同一组标识。API 不接收本地模型预测作为答案。JSON 保留结构化完整结果，CSV 为结果表，标注图的区域并不代表准确物体计数。

## 状态与持久化

任务从 queued 到 running，最终为 succeeded、partial、failed 或 interrupted。两侧分别记录 queued/running/success/error 等状态；未请求大模型时 api_status=skipped。先完成的一侧立即入库，另一侧失败时仍能查看、导出已有结果。

SQLite 位于数据目录 `tasks.sqlite3`，图片位于 `tasks/<系统生成的UUID>`。Windows 默认数据目录 `.local/stage3-data`，容器内 `/data` 对应宿主 `.local/container-data`，两者有意各用自己的验证数据。

只运行一个 API worker。同一数据目录由文件锁限制单实例；后台线程不是持久消息队列。服务重启会把遗留未完任务标 interrupted；若外部调用当时已经开始，则 api_status=unknown，需要人工核对记录或账单，禁止自动重发。

历史页读取已保存结果，刷新不调用模型。运行中不可删除，返回 409。终态删除会移除图片及两侧结果，保留提交编号墓碑和收费预留记录，不返还不确定的调用次数。文件删除和数据库提交尚不是跨介质原子事务；演示用单实例，不宣称具备生产级故障恢复。

## 收费控制

新环境默认 `GV_S3_PAID_MODE=limited`、`GV_S3_PAID_CALL_LIMIT=0`，禁止收费。云端最初两次测试已完成；用户要求取消测试上限后，使用新的授权编号和 `GV_S3_PAID_MODE=manual`。manual不限制总次数，页面仍默认不勾选，只有勾选并创建任务才发送本图并计费；刷新、历史、导出不收费。本机8080继续保持原配置。

请求入队时累计一次；limited检查次数上限，manual在数据库中使用call_limit=-1表示不限次数并继续累计。`/health/ready`返回paid_calls_mode，manual的paid_calls_remaining为null；这是无测试次数上限，不是免费。原有限授权不能在同一编号下改写为manual。网络失败、中断和删除均不自动退还次数，也不自动重试。服务商、模型配置在入队时捕获；执行前检查提示词哈希，远端请求强制单次尝试。提示词缺失在提交前返回409，不创建任务或消耗预留次数。配置指纹覆盖本地设置和当次非敏感API设置、提示词哈希，不包含密钥。当前配置为第三方 NexaVLinks 兼容接口，不能描述成已核实的 OpenAI 官方直连。

## 验证

`tests/test_stage3_service.py` 使用模型替身验证状态、预算、防重、恢复和删除边界，不证明模型识别效果。`scripts/verify_stage3_http.py` 才使用真实 HTTP 与原本地模型，核对图片哈希、导出、标注图及重复提交；其两张样例属于开发图，不是新测试集，不发送付费请求。
