## 架构与访问

```mermaid
flowchart LR
    B[本人浏览器18080] --> S[SSH加密通道]
    S --> N[服务器nginx回环8080]
    N --> W[Streamlit]
    N --> A[FastAPI]
    W --> A
    A --> D[(SQLite与任务图片)]
    A --> Q[单进程顺序执行]
    Q --> L[SAM2与CLIP / A10]
    Q --> M[显式勾选后调用NexaVLinks]
```

API只有一个worker；共享Bearer凭据不是多用户登录。重启将未完成任务标为中断，不自动重发收费请求。数据库结构版本为1，不兼容结构拒绝启动；没有通用跨版本迁移工具或高可用队列。
