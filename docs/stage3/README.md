## 结构

```mermaid
flowchart LR
    B[浏览器] --> N[nginx 本机8080]
    N --> W[Streamlit 页面]
    N --> A[FastAPI 接口]
    W --> A
    A --> D[(SQLite 与任务图片)]
    A --> Q[单实例后台顺序执行]
    Q --> L[SAM2 与 CLIP]
    Q --> M[已获新授权时的多模态服务]
    Q --> D
```

单进程后台执行适合本项目的小规模演示，不是 Redis/Celery 持久队列。API 只能使用一个 worker；SQLite 和文件锁共同约束同一数据目录的一份服务。数据库首次启动创建表，使用 user_version=1；只接纳列名一致的旧版未标版本数据，其他版本或列集合不符会拒绝启动。尚无通用跨版本迁移工具。
